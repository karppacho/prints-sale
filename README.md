# Учёт продаж тиражной графики

[![CI](https://github.com/karppacho/prints-sale/actions/workflows/ci.yml/badge.svg)](https://github.com/karppacho/prints-sale/actions/workflows/ci.yml)

Внутреннее веб-приложение по [ТЗ](ТЗ_Учет_продаж_картин.md) (v2.2):
остатки тиражей по номерам, продажи корзиной, постоплата и должники,
филиалы с перемещениями, роялти художникам, отчёты владельца с Excel.

## Статус

В эксплуатации у заказчика с июля 2026: два филиала (Москва и Санкт-Петербург),
продажи в магазине и на выездных ярмарках; продавцы, администраторы и владелец
работают в одной системе. Схема БД дорабатывалась миграциями по итогам
эксплуатации (0004–0006: справочник должников, отмена чеков продавцом,
объединение печати и подписи).

Репозиторий перенесён из рабочего одним коммитом; дальнейшая история — здесь.

## Стек

- **Фронтенд**: React 18 + Vite + TypeScript, Tailwind CSS, React Router 7
- **Бэкенд**: self-hosted Supabase на VPS (PostgreSQL + RLS/RPC, Auth, Storage,
  Edge Functions) — тот же проект, что и основная система (схема `public`);
  направление картин изолировано в схемах `art` и `finance`
- **Excel**: xlsx-js-style (форк SheetJS со стилями ячеек) в браузере
- **Права**: три роли (продавец / админ / владелец), защита на уровне БД —
  RLS-политики + RPC security definer; продавец и админ не видят ни одной суммы
  (кроме списка чеков своего филиала на экране отмены — ТЗ §3)
- **Проверки**: Vitest; GitHub Actions — типы, тесты, сборка на каждый push и PR

## Структура

```
src/
  lib/            supabase-клиент, запросы, форматирование, сжатие фото,
                  парсер номеров, FIFO-привязка выплат роялти, настройки (config.ts)
  auth/           вход по логину (<login>@<VITE_LOGIN_DOMAIN>), роль/филиал,
                  режим смены (магазин/ярмарка), автовыход в 23:59:59
  cart/           корзина + отправка чека (идемпотентный sale_id, повтор при сбое связи)
  components/     Layout (меню по ролям), сетка/карточки, шторка быстрой продажи
  pages/          экраны по ТЗ §5 (каталог, экземпляры, корзина, отмена чека,
                  очередь печати, приход, перемещения, должники, отчёты, выплаты,
                  управление)
  export/xlsx.ts  выгрузки Excel (детализация, сводки по художникам/способам/филиалам)
supabase/
  migrations/     0001 схемы art + finance, RLS, RPC (ТЗ §4.2 с исправлениями — см. шапку)
                  0002 сводный отчёт по направлениям
                  0003 view счётчиков каталога
                  0004 справочник должников (постоплата)
                  0005 права service_role для Edge Function
                  0006 отмена чеков продавцом/админом, печать ≡ подпись
  functions/manage-users/  Edge Function: создание/удаление учёток (ТЗ §4.3)
docs/
  DB_SETUP.md     развёртывание БД на VPS (миграции, PGRST_DB_SCHEMAS, владелец)
  DEPLOY_VPS.md   деплой фронтенда (nginx, CORS, обновление)
.github/workflows/ci.yml  CI: проверка типов, тесты, сборка
```

## Разработка

```bash
npm install
cp .env.example .env.local   # заполнить переменные (описание — в самом файле)
npm run dev                  # http://localhost:5173
npm test                     # unit-тесты (Vitest)
npm run typecheck            # проверка типов
npm run build                # typecheck + прод-сборка в dist/
```
